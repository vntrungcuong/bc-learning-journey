# Business Central AL Learning References

Use current Microsoft documentation as the primary technical reference for AL language and Business Central development behavior.

## Recommended topics
- Programming in AL
- Tables and table extensions
- Pages and page extensions
- Codeunits
- Events and triggers
- Interfaces and enums
- Reports
- Permissions
- Testing the application
- Test codeunits and test methods

## Internal learning material
The team also maintains `BCStudy.xlsx`, which includes a Customer Feedback practice track covering environment/project setup and foundational table practice. Use it together with this roadmap where the exercises overlap.

## Reference discipline
- Inspect the documentation that matches the Business Central/runtime version used by the project.
- Verify standard objects and available events against downloaded symbols before implementation.
- Treat examples in this learning pack as exercises, not as requirements for production design.
